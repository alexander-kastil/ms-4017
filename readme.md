# Manage and extend Microsoft 365 Copilot

Companion repository for [MS-4017: Manage and extend Microsoft 365 Copilot](https://learn.microsoft.com/en-us/training/courses/ms-4017), delivered by [Alexander Kastil](https://www.linkedin.com/in/alexander-kastil/). It holds the instructor demos: `readme.md` walkthroughs, curated Microsoft Learn links, and a few runnable Microsoft 365 agent projects.
