## Demos

| Demo | What it shows |
| --- | --- |
| [Set the update channel and swap security defaults for Conditional Access](01-prepare-env/demo-tenant-readiness-baseline.md) | Preparing a tenant is two jobs in two consoles, and the window between disabling security defaults and enabling Conditional Access leaves the tenant unprotected. |
| [Cap Copilot credit spend with a targeted spending policy](02-copilot-pag/demo-spending-policy.md) | Spending policy precedence works the opposite way to most expectations, and Copilot Studio bills through a different console entirely. |
| [Turn a Data Access Governance report into a site access review](03-sp-adv-mgmt/demo-oversharing-report.md) | The SharePoint Advanced Management loop from assessment score to report to a review request that moves the decision to the site owner. |
