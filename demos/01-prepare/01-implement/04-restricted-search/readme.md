# Restricted SharePoint Search

> **Retiring.** Restricted SharePoint Search (RSS) was only ever a short-term measure to buy time for permission/governance reviews. New enablement is **blocked from July 31, 2026**, and the feature is **fully retired by January 31, 2027**. RSS settings are **not** migrated automatically, so plan the transition to the replacement below.

[Restricted SharePoint Search](https://learn.microsoft.com/en-us/sharepoint/restricted-sharepoint-search)

## Replacement: Restricted Content Discovery (RCD)

Microsoft recommends moving to comprehensive data controls instead of RSS:

[Restricted Content Discovery (RCD)](https://learn.microsoft.com/en-us/sharepoint/restricted-content-discovery)

[SharePoint Advanced Management](https://learn.microsoft.com/en-us/sharepoint/advanced-management) - identify and remediate oversharing (broad access, unmanaged sharing).

[Microsoft Purview for AI](https://learn.microsoft.com/en-us/purview/ai-microsoft-purview) - sensitivity labels, DLP, and auditing for Copilot data governance.
